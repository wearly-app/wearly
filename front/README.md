# Wearly Frontend (Flutter)

Wearly 모바일 앱의 프론트엔드입니다. **Flutter**로 개발합니다.

> ⚠️ 이 디렉터리는 아직 비어 있습니다. 프론트엔드 담당자가 아래 절차로
> Flutter 프로젝트를 초기화해 주세요.

## 초기 세팅

이 `front/` 디렉터리 안에서 Flutter 프로젝트를 생성합니다.

```bash
cd front
flutter create .
flutter pub get
flutter run
```

> `flutter create .` 는 현재 디렉터리에 프로젝트를 생성합니다.
> 이 README는 덮어쓰지 않으니 안심하고 실행하세요.
